# Table Stakes — Poker

A mobile-friendly Texas Hold’em game you can play in your browser. Play against three computer opponents using virtual chips—no real money is involved.

**GitHub:** [man22418/Pocker-gan](https://github.com/man22418/Pocker-gan)

## How to play

1. Select **Deal Hand** to start a hand. Each player antes 10 chips.
2. On each street, choose **Check**, **Bet 10**, or **Fold**.
3. Play through the flop, turn, and river to reach the showdown. The best five-card poker hand wins the pot.
4. Select **Deal Next Hand** to continue.

The game includes a light/dark theme toggle and a responsive layout for mobile screens.

## Project files

- `index.html` — game page and table layout
- `styles.css` — responsive styling and themes
- `script.js` — game logic, opponents, and hand evaluation

Open `index.html` in a browser to play.
